# Test-only subjects

`em` (Electricity & Magnetism) and `engg-math` (Engineering Mathematics) were Prism subjects before the catalogue moved to PDEU's syllabus. Many tests, and the hand-written Gauss's-law sample lesson, are built on them, so `vitest.setup.ts` adds them to the catalogue **for tests only**. They are not part of the app and are not shown to students.
